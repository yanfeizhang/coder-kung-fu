# 你以為你的多核CPU都是真核嗎？多核“假象”

> 原文標題：你以为你的多核CPU都是真核吗？多核“假象”

> 原文連結：http://kfngxl.cn/index.php/archives/569/

---

提到CPU核數，相信絕大部分的同學想到的都是top命令，直接到自己的伺服器上看一下是多少個核。看到的核越多，貌似笑的越開心。比如說說我的CPU，用top命令展開以後，看到了有24核。那麼事實真是你想象的這麼美好嗎？

那麼是否就說明我的機器安裝的CPU真的有24核？其實不是的，我們透過top命令看到的CPU核也叫做 邏輯核 。 說到這裡我們先來普及一下基本概念：

物理CPU：主機板上真正安裝的CPU的個數，透過physical id可以查檢視

物理核：一個CPU會整合多個物理核心，透過core id可以檢視到物理核的序號

邏輯核： intel運用了超執行緒技術，一個物理核可以被虛擬出來多個邏輯核，processor是邏輯核序號

好了，我們瞭解完cpu的基本概念後，來找一臺機器真正看一下。在linux系統下，透過 cat /proc/cpuinfo 可以看到CPU更為詳細的資訊，在作業系統的視角看來是有24個邏輯核，但是在物理上很有可能多個邏輯核對應的是同一個物理核。如下所示例子：

實際檢視你的CPU

檢視物理CPU

可以看出，該實機有兩個物理CPU。

檢視物理核 #cat /proc/cpuinfo| grep "cpu cores"| uniq
cpu cores       : 6 cpu cores表示每個cpu有6個物理核心，因為有2個物理CPU，所以該機器總共只有12個物理核。而不是top命令裡看到的24個，整整少了一半。  Intel是透過超執行緒技術把一個物理核虛擬出來了多個，故而作業系統層面看到的比實際的物理核要多。我們尋找一下證據

檢視物理核

cpu cores表示每個cpu有6個物理核心，因為有2個物理CPU，所以該機器總共只有12個物理核。而不是top命令裡看到的24個，整整少了一半。  Intel是透過超執行緒技術把一個物理核虛擬出來了多個，故而作業系統層面看到的比實際的物理核要多。我們尋找一下證據

檢視邏輯CPU #cat /proc/cpuinfo  | grep -E "core id|process|physical id"
processor       : 0
physical id     : 0
core id         : 0
......
processor       : 12
physical id     : 0
core id         : 0
......
processor       : 23
physical id     : 1
core id         : 10 processor就是邏輯核的序號，可以看出該機器總共有24個邏輯核。大家注意看processor 0和processor 12的physical id、core id都是一樣的，也就說他們他們也處在同一個物理核上。但是他們的processor編號卻不一樣，一個是0，一個是12。這就是說，這兩個核實際上是一個核，只是透過虛擬技術虛擬出來的而已。

檢視邏輯CPU

processor就是邏輯核的序號，可以看出該機器總共有24個邏輯核。大家注意看processor 0和processor 12的physical id、core id都是一樣的，也就說他們他們也處在同一個物理核上。但是他們的processor編號卻不一樣，一個是0，一個是12。這就是說，這兩個核實際上是一個核，只是透過虛擬技術虛擬出來的而已。

超執行緒作用

超執行緒裡的2個邏輯核實際上是在一個物理核上執行的，模擬雙核心運作，共享該物理核的L1和L2快取。物理計算能力並沒有增加，超執行緒技術只有在多工的時候才能提升機器核整體的吞吐量。而且據Intel官方介紹，相比實核，平均效能提升只有20-30%左右。也就是說，在我剛才的機器上看到的24核的處理能力，整體上只比不開超執行緒的12核效能高30%。讓我們再用開發者使用的程序來看，由於你的程序被其它程序分享了L1、L2，這就導致cache miss變多，效能會比不開超執行緒要差。

所以說，作業系統看到的24核只是一個“假象” 。
