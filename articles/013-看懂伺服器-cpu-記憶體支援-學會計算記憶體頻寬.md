記憶體通道數與頻寬

下圖是 Skylake 的 CPU 的總體結構圖。

該 CPU 有兩個記憶體控制器（IMC，Integrate Memory Controller）。每個記憶體控制器上都有一個 DDR PHY。DDR PHY 是連線 DDR 記憶體條和 記憶體控制器的橋樑。它負責把記憶體控制器發過來的資料轉化成符合 DDR 協議的訊號，並傳給記憶體顆粒。也負責把記憶體返回給 CPU 的資料轉化成記憶體控制器認識的訊號，最終交給 CPU 核來處理。

每個 DDR PHY 有 3 個 DDR4 channels（通道）。每個 channel 有兩個記憶體插槽，也就是說可接 2 條 DIMM（關於 DIMM 後面會介紹，這裡把它理解為一個記憶體條就可以了）。

所以該代際 CPU 總共有 6 channels，最多可支援插入 12 條記憶體條。

每個記憶體通道都是可以獨立工作的。該 CPU 支援的記憶體資料頻率是 2666MT/s，理論上每秒鐘可以傳輸 2666M 次資料。由於現在都是 64 位的計算機。所以，可以算得

單通道記憶體頻寬 = 2666M 64 位元 = 2666M 8 位元組 = 21.33 GB/s

6個通道的總頻寬 = 21.33 GB/s * 6 = 128 GB/s

記憶體條模組規格

我們再來看 Skylake 記憶體控制器中支援的 RDIMM and LRDIMM。 那麼 RDIMM 和 LRDIMM 型別的記憶體是什麼呢？ 我們先來看 DIMM。

DIMM 是雙列直插記憶體模組，是現代最常用的記憶體條模組的規格，英文全名 Dual In-Line Memory Module。表示的是訊號接觸在金手指兩側，並且在 DIMM 條的邊沿作為訊號接觸面。

根據它的名稱可以看出歷史上曾出現過 SIMM（Single-Inline Memory Module）。SIMM 的位寬是 32 位，這是 32 位機時代的產物。到了 64 位機時代後，就統一都用 DIMM 了。Dual 的意思是 32 位的雙倍，64 位。這種規格一致延續至今。

針對不同的應用場景，記憶體條的標準也是不太一樣的。大致可以分為如下幾種。

UDIMM：無緩衝雙列直插記憶體模組 ，是 Unbuffered DIMM 的縮寫。

指地址和控制訊號不經緩衝器，無需做任何時序調整，直接到達 DIMM 上的各個 DRAM 晶片。這種記憶體要求 CPU 到每個記憶體顆粒之間的傳輸距離相等，這樣並行傳輸才有效。而保證 CPU 到每個顆粒之間傳輸距離需要較高的製造工藝，這樣就對記憶體的容量和頻率都產生了限制。這種記憶體由於容量小，所以在個人桌上型電腦上用的比較多。

下圖是一個桌上型電腦的 UDIMM 16GB 記憶體條。該記憶體條背面是空的，總共有八個黑色的記憶體顆粒。

另外上面這個記憶體條還標識了 16 GB 2R*8 PC4-3200AA-U82-11。

SO-DIMM：小外形模組 ，是 Small Outline DIMM 的縮寫。

在膝上型電腦出現後，對記憶體的體積和功耗都要求更小一些。SO-DIMM 就是針對膝上型電腦定義的標準。其寬度標準是 67.6 mm。如下圖是兩個筆記本記憶體條，可見體積要比桌上型電腦小不少。

RDIMM：帶暫存器雙列直插模組 ，是 Registered DIMM 的縮寫。 RDIMM 在記憶體條上加了一個寄存快取器（RCD，Register Clock Driver）進行傳輸。控制器輸出的地址和控制訊號經過Register晶片寄存後輸出到DRAM晶片。

CPU 訪問資料時都先經過暫存器再到記憶體顆粒。減少了 CPU 到記憶體顆粒的距離，使得頻率可以提高。而且不再像之前一樣要求每個記憶體顆粒傳輸距離相等，工藝複雜度因寄存快取器的引入而下降，使得容量也可以提高到 32 GB。主要用在伺服器上。

下圖是一個伺服器RDIMM 32 GB 記憶體條。這個伺服器記憶體條不光正面有很多記憶體顆粒，連背面也有。可見伺服器記憶體的顆粒數量比普通膝上型電腦、個人桌上型電腦的顆粒都要多很多。最關鍵的是記憶體條正中央位置的較大顆粒的寄存快取器，表明了這是一條RDIMM記憶體。

從圖中可見記憶體的引數標識是 32 GB 2R*4 PC4-2666V-RB2-12-DB1。

LRDIMM：低負載雙列直插記憶體模組 ，是 Load Reduced DIMM 的縮寫。

LRDIMM 相比 RDIMM 在引入寄存快取器 RCD 的基礎上，又進一步引入了資料緩衝器 DB（Data Buffer）。引入資料緩衝器作用是緩衝來自記憶體控制器或記憶體顆粒的資料訊號。實現了對地址、控制訊號、資料的全緩衝。成本更高，但可以支援更大容量。

ECC 記憶體

DRAM 記憶體是一種易失性的儲存，它是根據電容的電位高低來判斷儲存的是 0 或 1 的。但是電容電位雖然有定時重新整理來作為保障，卻仍然不能保證其讀取出來的資料和當時存進去的一致。如果出現了不一致，那這種現象就叫做位元翻轉。一根 8 GB 的記憶體條平均大約每小時會出現 1 - 5 個這樣的錯誤。

我們個人在辦公的時候，由於記憶體主要都用來處理圖片、影片等資料。即使記憶體出現了位元翻轉，可能影響的只是一個畫素值，沒有太大的影響，也很難感覺出來。

在伺服器應用中，處理的一般都是非常重要的計算，可能是一些推薦計算，也可能是一筆訂單交易，對出錯的容忍度是很低的。另外一臺伺服器經常是連續要執行幾個月甚至是幾年。因此總的來說，伺服器對穩定性的要求極高，不允許位元翻轉錯誤發生。

ECC 是一種記憶體專用的技術。它的英文全稱是 “Error Checking and Correcting”，對應的中文名稱就叫做“錯誤檢查和糾正”。從它的名稱中我們可以看出，ECC 不但能發現記憶體中的錯誤，而且還可以進行糾正。

在實現上，ECC 記憶體會板上額外再新增一個記憶體顆粒來專門負責檢查錯誤並糾正錯誤。

而不帶 ECC 的功能是沒有多出來的這個顆粒的。

CPU 每個 channel 支援同時支援 72 位的讀寫，其中 64 位是資料，另外 8 位用於 ECC 校驗。

由於有額外的硬體引入。所以 ECC 記憶體的價格會比普通記憶體要貴一些，速度也會慢 2% 左右。

總結

伺服器 CPU 比普通家用 CPU 貴的原因之一就是它對記憶體的支援和普通家用 CPU 不一樣。

首先就是伺服器的 CPU 對記憶體通道數的支援。普通家用 CPU 一般只有雙通道，最多也是四通道。而本文中提到的 Skylake 是 2015 年的伺服器 CPU，就已經支援了多達 6 個記憶體通道，最多可以支援 12 個記憶體條。2023 年 1 月釋出的第四代英特爾至強（Intel Xeon）更是支援了 8 記憶體通道。可以插更多的記憶體條。

另外就是伺服器模組。伺服器 CPU 支援 RDIMM（帶暫存器雙列直插模組）和 LRDIMM（低負載雙列直插記憶體模組）記憶體。這兩種記憶體單條都有更大的容量。

另外就是伺服器幾乎全系都支援 ECC 記憶體。而家用 CPU 只有最近幾年才開始支援 ECC。

我們再回到開篇提到的三個問題。

問題1：其中的 6 channle 是什麼意思？ 這值得是 CPU 支援的記憶體通道數量為 6 ，不同的通道可以並行工作，通道數量越高，訪問記憶體效能越好。

問題2：RDIMM、LRDIMM 又分別代表的是什麼記憶體？ RDIMM、LRDIMM 是在控制訊號上、或者資料訊號上加了一些硬體快取，有了這些快取可以支援單條做到更大的容量。製作工藝比較複雜，價格也會偏貴一些。

問題3：為什麼記憶體頻寬中 bandwidth 是 21.33 GB/s，aggregated bandwidth 128 GB/s？ 單通道記憶體的頻寬是根據記憶體的資料頻率計算出來的，由於資料頻率是 2666M，所以算得單通道頻寬為 21.33 GB/s。由於總共有 6 個通道，所以總的頻寬可以達到 128 GB/s。

不過要注意的是，廠商的引數中都指的之理論最大頻寬。而實際執行的過程中，記憶體硬體中會有各種延遲，實際頻寬到不了這麼高。
