# 你以為你的多核 CPU 都是真核嗎？多核「假象」

> 原文標題：你以为你的多核CPU都是真核吗？多核“假象”

> 原文連結：https://mp.weixin.qq.com/s/XX1yh8BTgT256pAnfosQkw

---

提到 CPU 核數，相信絕大部分的同學想到的都是   `top` 命令，直接到自己的伺服器上看一下是多少個核。看到的核越多，貌似笑的越開心。例如說說我的 CPU，用 `top` 命令展開以後，看到了有 24 核。那麼事實真是你想像的這麼美好嗎？

```
# top

Tasks: 596 total,   1 running, 595 sleeping,   0 stopped,   0 zombie
Cpu0  :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
Cpu1  :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
Cpu2  :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
Cpu3  :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
Cpu4  :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
......
Cpu23 :  0.0%us,  0.0%sy,  0.0%ni,100.0%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0%st
```

那麼是否就說明我的機器安裝的 CPU 真的有 24 核？其實不是的，我們透過   `top` 命令看到的 CPU 核也叫做邏輯核 (Logical Core)。 說到這裡我們先來普及一下基本概念：

- 實體 CPU (Physical CPU)：主機板上真正安裝的 CPU 個數，透過 `physical id` 可以查檢視。
- 實體核心 (Physical Core)：一個 CPU 會整合多個實體核心，透過 `core id` 可以檢視實體核心的序號。
- 邏輯核：Intel 運用了超執行緒 (Hyper-Threading) 技術，一個實體核心可以被虛擬出多個邏輯核， `processor` 是邏輯核序號。

好了，我們瞭解完 cpu 的基本概念後，來找一臺機器真正看一下。在 linux 系統下，透過  `cat` `/proc/cpuinfo` 可以看到 CPU 更為詳細的資訊，在作業系統 (Operating System) 的視角看來是有 24 個邏輯核，但是在實際上很有可能多個邏輯核對應的是同一個實體核心。如下所範例子：

## 實際檢視你的 CPU

- 檢視實體 CPU

```
#cat /proc/cpuinfo | grep "physical id" | sort | uniq
physical id     : 0
physical id     : 1
```

可以看出，該實機有兩個實體 CPU。

- 檢視實體核心

```
#cat /proc/cpuinfo | grep "cpu cores" | uniq
cpu cores : 6
```

`cpu cores` 表示每個  cpu 有 6 個實體核心。因為有 2 個實體 CPU，所以該機器總共只有 12 個實體核心，而不是 `top` 命令裡看到的 24 個，整整少了一半。Intel 是透過超執行緒技術把一個實體核心虛擬出多個邏輯核，故而作業系統層面看到的邏輯核數量會多於實際的實體核心數量。

- 檢視邏輯 CPU (Logical CPU)

```
#cat /proc/cpuinfo | grep -E "core id|process|physical id"
processor : 0
physical id : 0
core id : 0
......
processor : 12
physical id : 0
core id : 0
......
processor : 23
physical id : 1
core id : 10
```

`processor` 是邏輯核的序號，可以看出該機器總共有 24 個邏輯核。processor 0 和 processor 12 的 `physical id`、`core id` 都一樣，也就是處在同一個實體核心上。但是它們的 processor 編號不同，一個是 0，另一個是 12。這表示兩個邏輯核實際上共用同一個實體核心，只是透過虛擬技術產生出來的。

## 超執行緒作用

超執行緒裡的 2 個邏輯核實際上是在一個實體核心上執行的，模擬雙核心運作，共享該實體核心的 L1 和 L2 快取 (Cache)。硬體計算能力並沒有增加，超執行緒技術只有在多工的時候才能提升機器核整體的吞吐量。而且據 Intel 官方介紹，相比實核，平均效能提升只有 20-30% 左右。也就是說，在我剛才的機器上看到的 24 核的處理能力，整體上只比不開超執行緒的 12 核效能高 30%。讓我們再用開發者使用的程序 (Process) 來看，由於你的程序被其他程序分享了 L1、L2，這就導致 cache miss 變多，效能會比不開超執行緒要差。

所以說，作業系統看到的 24 核只是一個「假象」。
