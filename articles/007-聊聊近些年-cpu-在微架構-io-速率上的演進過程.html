聊聊近些年 CPU 在微架構、IO 速率上的演進過程

原文連結：http://kfngxl.cn/index.php/archives/587/

大家好，我是飛哥！

在上一篇 《深入瞭解 CPU 的型號、代際架構與微架構》 中我們介紹了我手頭的一顆 Intel(R) Core(TM) i5 的型號規則，以及它的物理硬體的 Die 圖結構。以及它對應的 Skylake 核的微架構實現。

不少同學開始問我其它型號的 CPU 和它比有什麼區別呢。考慮到了市場上各種新老 CPU 型號太多了，咱們沒辦法一一介紹。所以我想了一個辦法，咱們把這些年 CPU 進化的幾個關鍵點講一講。這樣將來大家再看其它的 CPU 的時候，也能做到懂得歷史，也能展望未來了。

一、製程工藝的變化

CPU 的生產過程大概是需要經過如下幾步： 第一步是晶圓的生產。具體過程是將包含有大量矽的石英沙放到一個巨大的石英熔爐中加熱融化，然後向熔爐中加入一個小的晶種以便於矽晶體圍著這顆晶種生長。直到生成一個單晶矽矽錠。這個矽錠是一個圓柱體，直徑大概在 200 mm 或 300 mm。然後對矽錠進行切割，將圓柱體的矽錠切割成圓形的晶圓。

第二步是 CPU 硬體電路的製作。晶圓表面會被塗上一層光阻物質，這種光阻物質後面被紫外線照到的地方會融化。接著使用固定波長的紫外線透過印著 CPU 複雜電路結構圖樣的模版照射晶圓。用光來對晶圓進行蝕刻。然後再透過沉積的方式加一層矽，塗光阻物質，再次影印，蝕刻重複多遍形成一個多層結構。而且每層中間都要填充金屬導體。最終在一個非常小的面積上形成一個比一座城市還要複雜的 3D 結構。

第三步是進行封裝和測試。晶圓上的電路被封裝起來，然後進行測試合格後就會推向市場銷售。

在上面的製作步驟中，最重要的是第二步。在這個過程中追求的是不斷底在單位面積的晶片上佈局更多的電晶體。每個電晶體的結構大概如下。

電晶體的尺寸越小，單位面積上的電路就越豐富，生產出來的 CPU 的效能就越好。另外還有就是電晶體越小的話，單個電晶體的能耗也會越低，整顆 CPU 也會越省電。

衡量電晶體尺寸大小的標準是電晶體中源極和柵極之間（溝道長度）的距離。在 Intel 歷年的 CPU 中，在 2013 年的 Haswell 採用的是 22 nm 的工藝。到了 2014 年的 Broadwell 開始採用 14 nm 工藝。到了 2019 年的 Ice Lake 開始引入 10 nm 工藝。到了 2022 年的 Raptor Lake，已經開始採用 7 nm 工藝了。

一般來說，製程工藝越短，生產出來的 CPU 也就越先進。

二、整合度的變化

CPU 雖然是最精密的裝置，但是它也是無法自己完成工作的。需要和計算機中的記憶體、顯示卡、硬碟、網絡卡、USB裝置、滑鼠鍵盤等元件配合才行。所以，CPU 需要透過硬體線路來和這些裝置相連。

在這些裝置中，所有硬體的工作頻率都比 CPU 要慢。只不過有的裝置雖然速度比不上 CPU，但是還是比較快的。另外一些裝置比如硬碟、鍵盤滑鼠相比更慢一些。 在老式 Intel CPU 中。

在大約 2000 年前後的老式電腦體系結構中，CPU 在主機板上設計了南橋和北橋兩個硬體。北橋負責與CPU通訊，並且連線高速裝置記憶體和顯示卡，並且與南橋通訊；南橋負責與低速裝置硬碟、網絡卡、鍵盤滑鼠、USB裝置通訊，並且與北橋通訊。

其中北橋晶片是儲存控制器(Memory Controller Hub, MCH)。功能包括了 PCIe（Peripheral Component Interconnect Express，是一種高速序列計算機擴充套件匯流排標準）匯流排功能用來連線顯示卡。也包括了記憶體控制器，用來連線記憶體。

後來由於 CPU 對記憶體和顯示卡的資料頻寬需求越來越大。Intel 從 2011 年正式釋出的 SandyBridge 開始，CPU 整合記憶體控制器和 PCIe 控制器，相當於是把原來北橋的功能整合在 CPU 內部了，北橋從那時開始就消失了（參考 https://en.wikichip.org/wiki/intel/microarchitectures/sandy_bridge_ (client)）。

隨著時間的推移，CPU 硬體整合度越來越高。在手機晶片中，已經 由於只剩下一個晶片了，也沒有“晶片組”的說法了，只剩下孤零零的PCH (Platform Controller Hub)。

未來隨著整合度的進一步提高，未來在桌上型電腦中南橋也可能會消失。在手機中由於體積的特殊性，已經實現了最高的整合度。透過系統級晶片（System on Chip，SOC）已經把 CPU、GPU、記憶體、導航定位模組、多媒體模組等全部整合到了一起。

三、記憶體控制器的變化

每代 CPU 的一大變化就是記憶體控制器的提升，一般來說，越新的 CPU 所支援的記憶體代際越來越新、支援的記憶體頻率越來越高。

先看 2011 年第 3 代的 Ivy Bridge。該代際下的的 CPU 支援的還是 DDR3 代的記憶體。 Celeron、Pentium 等系列的 CPU 支援的記憶體頻率大部分都是 DDR3-1333。只有 Core i3 和 Core i5 系列的記憶體頻率支援到了 DDR3-1600。

到了 2014 年第 5 代 Broadwell 開始，Intel 開始在多數的 Core 系列開始大規模地支援 DDR4-2400 記憶體。 2015 年的第 6 代 Skylake，其代際下高階的 Core i9 支援到了 DDR4-2666。到了 2016 年的 Kaby Lake，普通的 Core i5 和 Core i7 也都支援了 DDR4-2666。 2019 年的 Ice Lake 的 Core 系列支援了 DDR4 3200。

到了 2021 年的 Alder Lake S 開始，開始支援 DDR5 的新記憶體。而且還是同時支援 DDR4-3200 和 DDR5-4800。

上面說的是桌上型電腦的記憶體規格。對於膝上型電腦來說，還有對應的低電壓規格的記憶體條代際。低電壓標準的記憶體相對比較省電，但效能會差10%左右。在具體的記憶體標準上，包括 DDRxL 和 LPDDRx 兩個系列標準。其中其中 L 是低電壓 Low Voltage 的簡寫，LP 是 Low Power 的簡寫。

拿第 4 代記憶體來舉例， DDR4 的工作電壓雖然相比 DDR3 的 1.5 v 下降到了 1.2 v，更加省電。但是相比用在筆記本中的話，功耗仍然是比較高的。而 DDR4L 可以同時除了相容 DDR4 的 1.2 v 電壓模式外，還支援 1.05 v 的低電壓模式。LPDDR4 的工作電壓是 1.1 v，DDR4L 和 LPDDR4 所以更適用於用在膝上型電腦等移動裝置上。

CPU支援的記憶體除了以上指標外，還有另外一個就是通道數。直觀理解，就是 CPU 上可以支援幾條記憶體插槽。家用 PC 電腦一般都 2 個或 4 個記憶體插槽。在英文中對應的叫 channel 數。越多記憶體插槽的電腦支援的最大記憶體數量也就越大，整體頻寬也就更高。

四、PCIe 插槽變化

前面我們提到 PCIe 匯流排。它是一種用於連線高速元件的高速序列計算機擴充套件匯流排標準，它取代了歷史上出現的 AGP、PCI 和 PCI- X 匯流排標準，並經過了多次調整改進。

最早在 2003 年的時候，PCIe 1.0標準首次釋出。後來因為頻寬需求增長越來越快，已經陸續出現了 PCIe 1.0、PCIe 2.0、PCIe 3.0、PCIe 4.0 和 PCIe 5.0 等 5 代標準，PCIe 6.0也將在不久後釋出。傳輸速率每過一代就會增加很多。

Intel 的 CPU 發展過程中，在 2015 年的 Skylake 中支援了 PCIe 3.0 標準。在 2020 年的 Tiger Lake 的 CPU 中，開始支援了 PCIe 4.0 標準。在 2021 年的 Alder Lake S 中，提供了 16 通道的 PCIe 5.0 用於連線顯示卡，同時還支援 4 通道的 PCIe 4.0 通道用於連線固態硬碟。

五、微架構（核）的變化

在每代的 CPU 中，單個物理核的設計結構也是非常不同的。所以隔代的 CPU 效能差異也不盡相同。

在 2013 年和 2014 年，Haswell、Haswell Refresh、Broadwell 等代際採用的核的微架構設計都是一樣的，都採用的是 Haswell 微架構。

在 2015 年的 SkyLake、KabyLake、Coffee Lake 等代際中，採用的都是 Skylake 微架構。

到了 2019 年釋出的 Ice Lake 代際中，開始引入了 Sunny Cove 微架構。該架構下的單核效能大約比上一代提升了有 18% - 20%(參考 https://en.wikichip.org/wiki/intel/microarchitectures/sunny_cove )

每一種不同的 CPU 微架構，在核的內部實現細節上都會有一些不同。就拿 Ice Lake 中使用的 Sunny Cove 微架構來舉例，它相比上一代的 Skylake，具體的改進有如下。

對於負責指令解析的前端部分

µOP cache提升到了 2.3 k（上一代是 1536）

改進的分支預測

iTLB 快取翻倍

對於負責指令執行的後端部分

順序重排快取器（ReOrder Buffer，ROB）提升到了 352 條目（上一代是224條目）

排程器（Scheduler）提升到支援 10 路超標量（上一代是 8 路超標量），每個時鐘週期最多可以支援 10 個微操作

對於執行引擎部分

儲存操作埠提升到了 2 個（上一代是 1 個）

地址生成埠提升到了 2 個（上一代是 1 個）

對於快取子系統

L1 快取提升到了 48 KiB（上一代是 32 KiB）

L2 快取提升到了 512 Kib（上一代是 256 KiB）

STLB（Shared TLB）快取提升了到了 2048 條目（上一代是 1536 條目），DTLB也有較大改進

另外 Sunny Cove 還引入了一些新的指令，比如 AVX-512 向量指令。所有這些核設計細節中的提升，鑄就了 Sunny Cove 比上一代更強的單核效能。

到了 2020 年之後的 Tiger Lake 中，開始採用 Willow Cove 新微架構中 L2 又進一步提升到了 1.25 MB，L3 提升到了 12 MB。（參考 https://en.wikichip.org/wiki/intel/microarchitectures/willow_cove ）

後面到了 2021 年的 Alder Lake S 時為了平衡效能和功耗， 又開啟了一個新的 CPU 設計趨勢。就是借鑑手機 CPU 設計，引入了大核小核的設計區分。

在 CPU 的設計中，在效能核功耗上一直無法兼顧。內建更多的電晶體雖然可以提升效能，但會讓發熱功耗問題更嚴重。雖然製程不斷提升到了 22nm、14nm、10nm、7nm、...，但是由於晶片功能的增加和效能的提升，功耗上取得的效果一直不能令人滿意。

在傳統的 CPU 中，不管是什麼樣的任務，都採用一樣的核來排程和使用。但其實很多場景中，並不需要這些效能和能耗都較高的核。在新的設計趨勢中，“大核”叫做“Performance Cores”，小核”叫“Efficiency cores”。

當執行各種低負載應用時，可以使用“Efficiency cores”來滿足使用者需求的同時來節約電量，這種核的效能一般，但優勢在於省電。當真正需要有更多效能的時候，才會啟動更高效能的“Performance Cores”。

總結

由於市場上各種新老 CPU 型號太多了，咱們沒辦法一一去了解。我們只要掌握 CPU 發展中的幾個關鍵點的進步，就能夠做到對所有 CPU 有個基本的瞭解了。

其中最重要的進步點是 CPU 製程工藝的變化。衡量 CPU 製程工藝的尺寸的標準是電晶體中源極和柵極之間（溝道長度）的距離。在這些年中，製程一直在進步。從 65 nm、45nm、22nm、...、10nm、7nm一直在進步。但總體上來說，已經快到物理的極限，製程的進步速度在變緩。

另外一個就是整合度的變化。早年的 CPU 中，硬體架構上設計的比較細。在新的 CPU 中，由於對頻寬的要求變得越來越高。所以 CPU 硬體開發者們傾向於把更多的模組都整合到 CPU 硬體中。比如歷史上的北橋，絕大部分功能都被 CPU 硬體實現了。在手機晶片中，一個 SoC 更是整合了 CPU、RAM、導航定位模組、多媒體模組等眾多功能模組。

還有就是 IO 支援上的提升。對於記憶體控制器部分來說，支援的記憶體代際越來越高，從 DDR3、DDR4，一直到了今天的 DDR5。另外就是記憶體的頻率，即使是同一代際的記憶體，頻率支援的也是越來越高。還有就是連線顯示卡和固態硬碟的 PCIe 匯流排，也是從 1.0 逐步支援到了 5.0。

還有更重要的變化是單核微架構的設計。在新的單核架構中，CPU 中的各種快取如 TLB、L1、L2變的越來越大，支援的超變數路數也再變多。還有就是一個新的發展趨勢，CPU 廠商們引入了一些更省電的“Efficiency cores”，俗稱小核。用來在系統計算任務不重的時候，使用小核來排程，節約更多的能耗。

CPU硬體一直在進步，在過去的很多年中，伺服器端計算效能的提升都是靠硬體來提升的。但我覺得近些年來，這個提升趨勢有變緩的跡象。因此未來更好地理解硬體內部原理，好好設計和調優服務的軟體部分，讓硬體效能最大程度地發揮，這件事情會變得越來越重要。
