大家好，我是飛哥！

在10月16號的時候，Intel 正式釋出了第 14 代的酷睿處理器。但還有很多同學看不懂這種釋出會上釋出的各種 CPU 引數。藉著這個時機，我給大家深入地講講 CPU 的型號規則、代際架構與微架構方面的知識。

CPU 在整個計算機硬體中、技術體系中都算是最最重要的東西了。但很遺憾的是，80%以上的開發對 CPU 並不是很瞭解。所以在前面的文章中，我帶領大家深入地學習了很多核心中管理和排程 CPU 資源相關的文章。在今天，我想從另外一個角度，從 CPU 硬體相關的技術細節切入，帶領大家更好地認識 CPU。

我手頭有一臺之前用過的 ThinkPad x270 的膝上型電腦。在這臺電腦中的 CPU 型號是 Intel(R) Core(TM) i5-7200U CPU @ 2.50GHz 2.71 GHz 。那麼這個型號字串中都隱含了哪些技術資訊呢？今天，就讓我們以這個型號為切入點，深入地瞭解個人 PC 電腦中 CPU 硬體相關的技術點。

一、Intel 的 CPU 型號規則

無論是哪家 CPU 廠商，為了更好地管理自己生產的眾多型號的產品，也為了能更好地讓消費者對自己家的產品快速地瞭解。都會定義一套產品規則。對於 Intel 來說，它的命令規則大致如下：

Intel 把 CPU 的編號分成了品牌標誌、品牌修飾符、代際編號、SKU、產品線字尾五個部分。接下來我們分別展開對這五個部分來了解。

第一部分是品牌標誌。最最常見的 x86 CPU 品牌包括 Intel 和 AMD 兩家公司。而 Intel 又面向不同的市場需求，包括凌動、賽揚、奔騰、酷睿、至強等多個子品牌。

酷睿（CORE）、賽揚（CELERON）、奔騰（PENTIUM）都是應用在家用 PC 電腦上的品牌。其中奔騰和賽揚這兩個品牌已經算作是歷史了。奔騰在 1992 年推出，之後再很長一段時間裡是 PC 家用電腦的主流。賽揚是 1998 年是為了和 AMD 競爭低價市場推出的產品，可以理解為縮水版的奔騰。酷睿是 2006 年推出，直到現在仍然是是 PC 電腦裡的主流品牌。

志強（Xeon）是企業級的CPU，多用於伺服器和工作站。大家在工作中使用的線上伺服器，基本都是這個子品牌旗下的產品。

凌動（Atom）主打省電和低功耗，主要用在手機平板等裝置上。是的，Intel 也是做過手機 CPU 的，但因為功耗問題在競爭中被 arm 架構各家處理器廠商打敗，在 2016 年後逐漸退出市場。

第二部分是品牌修飾符。這個部分是為了區分處理器的市場定位的，一般來說同一年代生產的 CPU 中， i3 i5 i7 i9 的效能是依次遞增的。分別代表著低端、中端和高階的定位。

第三部分是 CPU 的代際編號。這一部分有可能是一位數字，也有可能是兩位的數字。在我們舉例的這顆 CPU 上，代際編號是“7”。這個代際編號對應的是 Intel 於 2016 年推出的內部代號為“Kaby Lake” 的 CPU架構。一般來說，CPU 代際編號越大，則代表架構推出的時間點越新。單核的效能也會更好。關於“Kaby Lake” 後面我們還會單獨介紹。

第四部分是 SKU 編號。這是個 CPU 廠商為了方便對所有的產品進行庫存管理而制定的編號。這類似於超市裡商品的條形碼、圖書的 ISBN 號，方便查詢和管理產品的庫存量。一般來說，這個值也是越大效能越好，但不絕對。

第五部分是產品線字尾。在膝上型電腦中，H代表的是高效能、U系列代表的是較低功耗、Y系列代表的是極低的功耗。在桌上型電腦中，X代表的是最高效能、K代表的是高效能、T代表的是功耗最佳化。

關於型號規則大家也可以參考 Intel 的官網介紹（ https://www.intel.cn/content/www/cn/zh/processors/processor-numbers.html ）。

現在我們再回頭來看一下我們開頭提到的 CPU， Intel(R) Core(TM) i5-7200U CPU 。這裡麵包含的含義就是，這是一個Intel 的酷睿子品牌的 CPU，i7代表著中高階，代際編號是7，這個代際的處理器架構是 2016 年釋出的採用的 Kaby Lake 架構生產的。SKU 編號是 200。產品線字尾的 U 代表的是低功耗，比較省電，同時也就代表著效能並不是最強的。

在看最新的釋出的酷睿 CPU 型號有， Intel(R) Core(TM) i9-14900K 、 Intel(R) Core(TM) i7-14700K 、 Intel(R) Core(TM) i5-14600K 等幾款 CPU。這裡面也表示了還是屬於 Intel 酷睿 子品牌下的產品。i9、i7、i5分別代表著每個 CPU 的檔次。14 代表的是代際。900、700、600 屬於 SKU 編號。

二、CPU 的代際

前面在看到 Kaby Lake 的時候，肯定很多小夥伴都會表示看不懂這是什麼意思。所以這裡專門準備一個小節來解釋下。前面我們提到每個 CPU 型號中都包含了一個代際編號。比如第 7 代、第 8 代，就在剛剛 2023 的 10 月 16 日，已經更新到了第 14 代。

這個代際代表的 CPU 的生產年份不同、生產工藝不同、架構設計的不同。各個代際除了這個數字的編號外，還會有一個英文代號。比如第 7 代的代際編號就是 Kaby Lake。最新的第 14 代的代際編號是 Raptor Lake Refresh。下表是我搜集整理到的各個代際的資訊。

在 Die圖中，最上方的Memory Controller 是記憶體控制器。當前 CPU 能支援什麼樣規格的記憶體，以及能支援多大的記憶體，都是由 CPU 中的記憶體控制器來決定的。其中 Kaby Lake 的記憶體控制器相比上一代 Skylake 來說，將支援的記憶體頻率從 DDR4-2133 提升到了 DDR4-2400。

中間位置是兩個物理核，這是 CPU 中最重要的部分。還有兩塊 L3 Cache，要注意的是雖然在硬體上是有兩塊 L3，但不管有幾塊，所有的 L3 快取都是所有核共享的。

在CPU 的最右側的 Gen9.5 是 CPU 中整合顯示卡。因為我們不打算深入講顯示卡，所以這裡大家只要知道 PC 電腦的 CPU 裡是包含一塊整合顯示卡的就夠了。對這塊顯示卡感興趣的同學可以移步 https://en.wikichip.org/wiki/intel/microarchitectures/gen9 。

在 CPU 的最左側是 System Agent 模組。在該模組中主要包括外圍元件快速互聯（Peripheral Component Interconnect Express，簡稱PCIe） 通道、影象處理單元（Image Processing Unit，IPU)等

在 Kaby Lake 中包含 20 個 PCIe 通道。其中有的通道是用於和顯示卡通訊，有的是和透過南橋和硬碟、網絡卡等裝置通訊。

南橋晶片是用於幫助 CPU 和外圍裝置互動的。固態硬碟、機械硬碟、網絡卡等 IO 裝置一般來說都是透過南橋來和 CPU 相連的。南橋會收集好了這些裝置上的資料再傳輸給 CPU 處理。另外現在有些高效能的固態硬碟也是直接透過 PCIe 通道和 CPU 通訊，這樣的硬碟效能更好。

另外 IPU 的功能是支援影片錄製成像、人臉檢測識別等影象相關處理的硬體支援。

以上就是 Kaby Lake 架構下 CPU 的主要物理結構。

另外從表中還可以看到 Kaby Lake 是2016年釋出的，製程工藝是 14 nm。CPU 的製程工藝一直在進步，從 2013 年的 22 nm 逐步發展到了今天的 7 nm。製程工藝的進步帶來的好處主要是能效比的提升，單位面積上電晶體的數量增加了，但是需要的能耗卻變低了。（本文來自於公眾號「開發內功修煉」）

三、物理核微架構設計

另外每個代際的 CPU 還有個非常不同的地方在於微架構的不同。微架構指的是每個物理核設計時採用的技術方案。不同的微架構對核的設計是不同的，比如 TLB、L1、L2 等各種快取，再比如 CPU 核內部的運算單元都會有所不同。

透過上一節中的表格，可以看到我手頭的這顆 Intel(R) Core(TM) i5-7200U CPU 代際編號為Kaby Lake，微架構的設計仍然沿用的是 Skylake 中的核設計。那麼 Skylake 中的物理核是怎麼設計的呢？我從官網站到了它的內部物理結構。

[](圖5.png)

上面的圖中大致可以根據顏色的不同分成三大塊區域。

第一塊區域是黃色部分的前端，也叫 Front End 。

其中前端部分的作用地從記憶體中獲取指令並解碼，然後把解碼後的指令放到佇列中，等待 CPU 後端處理。還包括了 CPU 中的分支預測的實現 BPU。另外也還包含解析指令是需要用到的 L1 指令快取和指令 TLB。

其中從上圖中也可以看到，Skylake 核中的 L1 指令快取的大小是 32 KiB。

第二塊區域是綠色的後端，又叫 Execution Engine 。

後端模組的作用是從佇列中獲取前端解碼好了的指令開始執行。在後端中包括 Port0、Port1、...、Port7 等 8 個埠。每個埠都支援不同的微操作（uOP）的處理。

其中 Port0、Port1、Port5、Port6支援整數、浮點數的加法運算，Port2、Port3 用於地址生成和載入，Port4用於儲存操作。每個

因為有 8 個 Port，所以後端在一個時鐘週期內，是可以最多處理 8 個微操作的。

第三塊區域是紫色的儲存系統，又叫 Momory SubSystem 。

在這裡包括了 L1 級別的 Data 快取區，圖中也展示了它的大小是 32KiB。還包括 L2 快取，其大小是 256 KiB。另外還有 Data TLB 等快取。這些快取都是位於 CPU 核內部的。訪問它們的速度比訪問記憶體更快。（本文來自於公眾號「開發內功修煉」）

不同代際的 CPU 的微架構設計也是不同的，單核效能也會有變化，後面的文章裡我們再講。

總結

今天藉助我手頭的一枚老舊的 CPU Intel(R) Core(TM) i5-7200U CPU @ 2.50GHz 2.71 GHz 。咱們深入地介紹了 Intel 的 CPU 命名規則。瞭解了命名規則有助於你快速判斷一顆 CPU 的大概的效能。不過如果你是一名發燒友，還是建議你搜尋天梯圖來了解每個 CPU 的排名情況。

另外我們也找到了這顆 CPU 的硬體解剖圖 - Die 圖。從 Die 圖裡我們直觀地看到了 CPU 內部的物理結構。在 i5-7200U 中包括了整合顯示卡、包括了物理核、還看到了 L3 快取的位置。另外記憶體控制器也是整合在 CPU 的，CPU 就是透過它來和記憶體通訊的。還有就是 PCIe 通道，是 CPU 用來和硬碟、網絡卡、顯示卡等裝置的通路。

最後我們深入到了 Skylake 的物理核的內部。瞭解到了物理核中的三大組成部分：前端、後端和儲存模組。其中前端負責指令的解析，後端負責指令解析後的微操作的執行處理。儲存系統為前端和後端提供了 L1、L2 等快取，用於加速記憶體訪問。
